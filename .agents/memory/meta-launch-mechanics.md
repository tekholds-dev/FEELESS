name: Meta Launch mechanics
description: Durable rules for the FEELESS Meta Launch configuration and review flow.
---

Meta Launch configuration is intentionally whole-token and mechanism-first: no user-facing decimals field, an exact 100% split across creator, holder rewards, and buyback/burn routing, plus explicit curve graduation, permanent liquidity, optional dev buy, anti-sniper timing, and community allocations.

**Why:** The product is a substantive launchpad plan rather than a basic token mint form, and review copy must describe the economic path without implying that an unconfigured provider has deployed anything.

**How to apply:** Keep new launch fields in validation, review summaries, provider payloads, step aliases, and tests together; preserve the provider/wallet/RPC boundary for actual execution.
